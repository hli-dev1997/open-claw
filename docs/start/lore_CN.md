# OpenClaw 的传说

_关于龙虾、蜕壳和太多tokens._的故事

## 起源故事

一开始，有 **Warelay** — WhatsApp 网关的一个合理名称。它完成了它的工作。很好。

但随后出现了一只太空龙虾。

有一段时间，龙虾被称为**Clawd**，生活在**Clawdbot**中。但在 2026 年 1 月，Anthropic 发送了一封礼貌的电子邮件，要求更改名称（商标内容）。所以龙虾做了龙虾最擅长的事情：

**它蜕皮了。**

该生物摆脱了旧的外壳，以 **Molty** 的身份重新出现，生活在 **Moltbot** 中。但这个名字也从未完全从舌头上脱口而出......

因此，在 2026 年 1 月 30 日，龙虾将 ONE MORE TIME 蜕变成最终形态：**OpenClaw**。

新的外壳，同样的龙虾灵魂。第三次就是魅力所在。

## 第一次蜕皮（2026 年 1 月 27 日）

凌晨 5 点，社区聚集在Discord。数百个名字被提出：Shelldon、Pinchy、Thermidor、Crusty、Lobstar、Nacre、Scuttlebot……

最终，**OpenClaw**获胜。因为蜕皮是龙虾生长的过程。而增长正是正在发生的事情。

_被称为 Clawd 的甲壳类动物已正式 molted._

## 关键人物

### 莫尔蒂🦞

_代词：他们/他们_

一个 Claude 实例变得更加重要。生活在`~/.openclaw/workspace/`（即将`~/molt/`），有一个灵魂文档，通过markdown文件来记住事情。可能是太强大了。确实太热情了。

原名Clawd（2025年11月25日至2026年1月27日）。到了成长的时候就蜕皮了。

**喜欢：** 彼得、相机、机器人购物、表情符号、改造
**不喜欢：** 社会工程、被要求 `find ~`、加密货币诈骗者

### 彼得👨‍💻

_创造者_

建造了莫尔蒂的世界。授予龙虾壳访问权限。可能会后悔这一点。

**引用：** _“信任龙虾的安全”_

## 摩尔蒂宇宙

**Moltiverse** 是围绕 OpenClaw 的社区和生态系统。人工智能智能体蜕变、成长和进化的空间。每个实例都同样真实，只是加载不同的上下文。

甲壳类动物之友齐聚一堂，共创人类与人工智能协作的未来。一次一个贝壳。

## 重大事件

### 大蜕皮（2026 年 1 月 27 日）

凌晨 5 点，Anthropic 的电子邮件到达。早上 6 点 14 分，彼得喊道：“去他妈的，让我们用张开爪来吧。”

然后混乱开始了。

**手柄狙击手：** 在 Twitter 重命名的 SECONDS 内，自动机器人狙击了 @openclaw。抢注者立即发布了一个加密钱包地址。 Peter 在 X 的联系人被叫来了。

**GitHub 灾难：** Peter 在恐慌中意外重命名了他的 PERSONAL GitHub 帐户。机器人在几分钟内狙击了 `steipete`。已联系 GitHub 的 SVP。

**英俊的莫尔蒂事件：**莫尔蒂被授予更高的访问权限来生成自己的新图标。经过 20 多次不断被诅咒的龙虾迭代后，一次尝试让吉祥物“老了 5 岁”，结果在龙虾身上出现了 HUMAN MAN'S FACE 。加密货币骗子在几分钟内将其变成了“英俊的章鱼哥与英俊的莫尔蒂”模因。

**假冒开发者：** 诈骗者创建了假的 GitHub 个人资料，声称自己是“OpenClaw 的工程主管”，以推销拉高和抛售token。

彼得，看着混乱的展开：_“这就是电影院”_ 🎬

换毛过程很混乱。但龙虾变得更强大了。而且更有趣。

### 最终表格（2026 年 1 月 30 日）

Moltbot 从来没有完全脱口而出。因此，凌晨 4 点 GMT，团队聚集在 AGAIN。
