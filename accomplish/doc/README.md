# 文档整理索引

本目录按主题收纳文档副本。目录名保持英文短横线命名，便于脚本、搜索和跨平台路径处理；中文说明见下表。

| 目录 | 中文说明 | 内容 |
| --- | --- | --- |
| `repo-overview` | 仓库总览 | `AGENTS_CN.md`、`README_CN.md`、`VISION_CN.md` |
| `concepts-architecture-runtime` | 架构、智能体运行时、模型与会话 | 第一梯队概念文档的英文原文和中文 `_CN.md` 副本 |
| `concepts-context-prompt` | 系统提示词、上下文与压缩 | `system-prompt`、`context`、`context-engine`、`compaction` 的中英文成对副本 |
| `concepts-delivery-queue` | 流式响应、分块、队列与 steering | `streaming`、`queue`、`queue-steering` 的中英文成对副本 |
| `concepts-memory-workspace` | 记忆系统、记忆搜索与工作区 | `memory`、`memory-search`、`agent-workspace` 的中英文成对副本 |

## 命名规则

- 英文原文保留原文件名，例如 `agent-loop.md`。
- 中文译文使用 `_CN.md` 后缀，例如 `agent-loop_CN.md`。
- 同一主题目录内，中英文文件成对存放，便于对照阅读。
